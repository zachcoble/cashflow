# CashFlow

## Run and data

Install requirements from requirements.txt in a suitable isolated Python environment and run `python main.py`; the existing project notes identify port 8000. The existing main.py binds 0.0.0.0 (all interfaces); this setup has not started or changed the service. Review exposure before running it on another computer. The live cashflow.db holds personal information and must stay outside Git. Back it up separately before changing schema or data.
